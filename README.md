# MERN Authentication System

A production-ready authentication system built using React, Node.js, Express, MongoDB, JWT and Refresh Tokens.

## Features

- User Registration
- User Login
- JWT Authentication
- Refresh Tokens
- Protected Routes
- Role Based Access Control
- Edit Profile
- Change Password
- Forgot Password
- Reset Password
- Auto Token Refresh
- Logout

## Tech Stack

Frontend
- React
- React Router
- Axios

Backend
- Node.js
- Express.js
- MongoDB
- JWT
- Bcrypt
